# Advogados Humaitá — Landing Page

Landing page institucional de alta performance para o escritório **Advogados Humaitá**, especializado em **Direito Trabalhista** e **Direito de Família & Sucessões**.

Desenvolvido com foco em velocidade máxima, zero dependências de Node/npm, tipografia cinemática e reprodução de vídeos em alta definição de ponta a ponta.

---

## 🏛️ Estrutura do Projeto

```
advocacia_lp/
├── index.html                  # Landing Page completa (HTML5 Semântico + Tailwind)
├── assets/                     # Vídeos cinemáticos e fotografia dos sócios
├── css/                        # Estilos e componentes customizados
└── js/                         # Interações e animações em Vanilla JavaScript
```
